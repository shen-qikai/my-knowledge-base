# NBTI

## 1. 什么是 NBTI？

NBTI（Negative Bias Temperature Instability）是 MOSFET 的一种可靠性退化机制，主要研究 PMOS 在负栅极偏压和高温条件下的性能退化。

## 2. 主要影响

NBTI 可能导致以下变化：

- 阈值电压 Vth 发生漂移
- 驱动电流 Idsat 下降
- 电路性能随时间退化

## 3. 退化机制

NBTI 与栅氧化层及 Si/SiO2 界面处的缺陷产生和电荷俘获有关。

## 4. 总结

NBTI 是 PMOS 器件可靠性研究中的重要课题。
